This is exploratory, personal-relevance evaluation for one annotator. The primary metric was in the run manifest; the all-pairs testing family was fixed in this analysis turn, not preregistered before collection. Weeks are the units, not the 49 slots or 122 distinct papers. Intervals enumerate all 823543 bootstrap resamples of seven whole weeks, percentile 95%; pairwise intervals are pointwise, not simultaneous. Tests enumerate all 128 paired sign flips, using absolute mean differences; validity requires independent weeks and exchangeability of the signs under the null. Adjacent weeks may be dependent. No normality assumption or normality pretest is used. Holm correction covers all ten comparisons. With seven weeks the minimum two-sided p is 0.015625, so this ten-comparison Holm procedure cannot reject any pair at 0.05. Non-significance does not imply equivalence. Small-sample bootstrap intervals may be optimistic. One model run per task cannot estimate model randomness separately. Dates overlap development exposure and two pooled papers had prior labels, so this is not a pristine holdout. Only selected papers were labeled: full-corpus recall cannot be calculated. The intervals generalize to similar weeks only under the sampling assumptions, not to other researchers. No verified gpt-6-sol pricing is recorded, so dollar cost remains unknown; token use is measured. Agent wall times exclude shared corpus collection/ranking and are affected by concurrency. Baseline timing was not recorded, and is not set to zero.
